Target Cartesi Rollups contracts `v3.0.0-alpha.10`. The `cartesi` devnet chain now comes from `@cartesi/client` (replacing `@cartesi/viem`), and contract bindings are generated by `@cartesi/wagmi-plugin` (replacing `@cartesi/devnet` and `@cartesi/rollups`). Self-hosted applications are now deployed with the `InputBox` address directly instead of encoded data-availability bytes, and are ownerless, so the connected wallet no longer becomes the application owner.
