# @sunodo/web

## 0.4.0

### Minor Changes

- 9160f97: Target Cartesi Rollups contracts `v3.0.0-alpha.10`. The `cartesi` devnet chain now comes from `@cartesi/client` (replacing `@cartesi/viem`), and contract bindings are generated by `@cartesi/wagmi-plugin` (replacing `@cartesi/devnet` and `@cartesi/rollups`). Self-hosted applications are now deployed with the `InputBox` address directly instead of encoded data-availability bytes, and are ownerless, so the connected wallet no longer becomes the application owner.
- 3a635e2: Add a withdrawal output builder option to the deploy page. Besides pasting the address of an existing `IWithdrawalOutputBuilder` implementation, users can now deploy a USD withdrawal output builder for an ERC-20 token via the `UsdWithdrawalOutputBuilderFactory` (deployed on supported testnets), which reuses an already-deployed builder for the same token when one exists.

### Patch Changes

- d34eb41: Update dependencies to their latest releases (Next 16.4, React 19.3, Mantine 9.7, Storybook 10.6, viem 2.57, TypeScript 7). wagmi stays on v2 until RainbowKit supports wagmi 3.
